Third-party software in BailanCraft's tesseract\ folder
=====================================================

BailanCraft bundles Tesseract OCR so it can recognise Thai text. Tesseract runs as a separate
program (tesseract.exe); BailanCraft does not link to it. These files come unmodified from the
UB Mannheim build of Tesseract for Windows (https://github.com/UB-Mannheim/tesseract), version
5.4.0.20240606; only the DLLs tesseract.exe loads are included.

                           https://github.com/tesseract-ocr/tesseract
Language data ............ Apache License 2.0 (licences\tessdata-LICENSE)
  tessdata\tha.traineddata, tessdata\eng.traineddata: tesseract-ocr/tessdata_best
  tessdata\osd.traineddata, tessdata\configs, tessdata\tessconfigs: the UB Mannheim build
